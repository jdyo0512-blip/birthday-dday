# 생일 디데이 🎂

수아·가족·친구들 생일을 한눈에 모아 보는 작은 웹앱.

## 화면 3개

- **홈** — 가장 가까운 생일을 히어로 카드로 크게 보여줘요. 생일자마다 고른 오일파스텔 손그림 캐릭터 스티커와 큰 D-Day 숫자, `🎉 축하 폭죽` · `💌 카드 저장` · `📅 캘린더 알람(.ics)` 버튼이 있어요. 아래에는 등록된 생일 카드가 캐릭터 스티커·카테고리 뱃지와 함께 정렬돼 있어요(카드를 누르면 축하 카드 · 캘린더 알람 · 수정 · 삭제).
- **달력** — 이전/다음 달 이동, 오늘 강조. 생일이 있는 날에는 파스텔 태그로 이름이 표시되고(음력 생일은 그해 양력으로 자동 계산), 날짜를 누르면 그날 생일자 상세 카드가 열려요.
- **업커밍** — `전체 · 가족 · 친구 · 기타` 필터, 세로 타임라인으로 월별 묶음 + D-N 카운트다운과 캐릭터 썸네일. 개별 또는 전체 생일을 `.ics`로 내보내요.

## 캐릭터·파티 소품 스티커 12종

동물 7종 `강아지 · 곰돌이 · 토끼 · 고양이 · 병아리 · 판다 · 다람쥐`(전부 파티 고깔모자 착용) + 파티 소품 5종 `케이크 · 풍선 · 선물상자 · 컵케이크 · 가랜드` — `assets/sticker-*.png`(480px, 256색) 오일파스텔 손그림. 생일 추가/수정 시트에서 4열 3줄 그리드로 고를 수 있고, 홈 히어로 · 생일 카드 목록 · 달력 상세 · 업커밍 타임라인 · 1080×1350 축하 카드 PNG에 그대로 들어가요. 스티커가 없는 예전 데이터는 이모지를 가장 비슷한 캐릭터로 옮기고, 그것도 없으면 이름으로 정해져요.

## 축하 카드 배경 6종

축하 카드 모달 아래 작은 썸네일 6개로 배경을 고르면 미리보기와 `PNG로 저장하기`(1080×1350 Canvas)에 똑같이 그려져요. 고른 배경은 생일 카드(사람)마다 `localStorage`에 함께 저장됩니다.

| id | 이름 | 모습 |
| --- | --- | --- |
| `cream` | 코지 크림 | 따뜻한 크림 바탕 · 파스텔 도트 · 점선 테두리 (기본) |
| `green-star` | 연두 별 | 크림 바탕 · 연두 손그림 세로 스트라이프 테두리 · 하늘색 별 |
| `blue-star` | 블루 별 | 파스텔 블루 수채 프레임 · 노란 작은 별 · 가운데 흰 종이 |
| `gingham` | 깅엄 체크 | 코랄/레드 깅엄 체크 테두리 · 둥근 크림 속지 |
| `daisy` | 데이지 | 상단 크림 · 하단 초록·하늘 스트라이프 · 하얀 데이지 · 빨간 점선 프레임 |
| `butter-stripe` | 버터 줄 | 버터 옐로우 바탕 · 파란 손그림 세로 실선 · 흰 라벨 카드 |

## 기능

- 음력 → 양력 변환(KASI 데이터, 2023~2049) · 생일 추가/수정/삭제 · 카테고리(가족·친구·기타)
- `.ics` 캘린더 알람: D-7 오전 9시와 당일 오전 9시 알람이 들어간 표준 iCalendar 파일
- 축하 폭죽, 1080×1350 PNG 축하 카드 저장(배경 테마 6종)
- 헤더의 **Aa 글씨체** 버튼으로 주아체 · 개구체 · 박다현체 · 감자꽃체 중 골라 쓸 수 있어요(선택은 브라우저에 저장되고 카드 PNG에도 반영)
- 아이폰 홈 화면에 추가하면 앱 아이콘(`assets/apple-touch-icon.png`)과 이름(`생일 디데이`)으로 열려요
- 생일 정보는 서버로 가지 않고 브라우저 `localStorage`에만 저장됩니다(기존 `dday.birthdays.v1` 데이터 호환).
