# 생일 D-day 🎂

수아·가족·친구들 생일을 한눈에 모아 보는 작은 웹앱.

- 가장 가까운 생일은 스포트라이트 카드로 크게 보여줘요.
- 생일 추가/수정/삭제, 음력 → 양력 변환(2023~2049), 축하 폭죽, 축하 카드 PNG 저장.
- 헤더의 **Aa 글씨체** 버튼으로 주아체 · 개구체 · 박다현체 · 동글체 중 골라 쓸 수 있어요(선택은 브라우저에 저장되고 카드 PNG에도 반영).
- 생일 정보는 서버로 가지 않고 브라우저 localStorage에만 저장됩니다.
